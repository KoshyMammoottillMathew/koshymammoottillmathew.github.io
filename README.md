## 🚀 Featured AI Project — SignBridge AI

> **Deep-learning ASL fingerspelling-to-text recognition using temporal sequence modelling.**

[![SignBridge AI](https://img.shields.io/badge/Explore-SignBridge_AI-7C3AED?style=for-the-badge)](https://koshymammoottillmathew.github.io/projects/signbridge-ai/)
[![Source Code](https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/KoshyMammoottillMathew/SignBridgeAI)

**SignBridge AI** is an end-to-end deep-learning system for continuous ASL fingerspelling-to-text recognition.

The pipeline combines:

```text
Video → MediaPipe Hand Landmarks → Temporal Conv1D → Bidirectional GRU → CTC → Text
```

**Key technologies:** Python • TensorFlow/Keras • MediaPipe • OpenCV • NumPy • Pandas • Gradio

**Model highlights:**
- 63 hand-landmark features per frame
- Temporal Conv1D + Bidirectional GRU architecture
- CTC sequence recognition
- 2.34M model parameters
- 16.32% best validation CER
- 15.96% later cached FSBoard test-split CER
- Interactive webcam prototype for near-real-time recognition
